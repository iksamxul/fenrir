Requirements

What each PC needs.

The host’s PC

  • Windows 10 or 11. Fenrir runs in its own window and can start with Windows.
  • Memory for the pack. The Dashboard’s memory planner shows what fits, with the game too if you play on the same PC.
  • Room for the pack and its backups. About 4 GB for All the Mods 10.
  • Java comes by itself. The Doctor installs the version the pack needs.
  • An internet connection. A free playit tunnel gives the game its address, with no router changes.

A friend’s PC

  • Windows 10 or 11.
  • TLauncher. Fenrir Connect sets up its profile and memory.
  • About 1.7 GB the first time for All the Mods 10, mostly straight from CurseForge.
  • The link from the host. It carries the key, so nothing needs pasting.

SmartScreen

Windows may say it protected your PC.

Fenrir is not signed by a big publisher, so SmartScreen can stop the Setup the first time. Choose More info, then Run anyway.

Check a download

The checksum should match.

In PowerShell, in the folder with the file, this prints its SHA-256. Compare it with the one on the card above.

Get-FileHash .\FenrirSetup.exe -Algorithm SHA256
