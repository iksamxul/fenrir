Getting started

What do my friends need?

Windows 10 or 11 and TLauncher. They open the link you send, run Fenrir Setup and press Install & Play. About 1.7 GB downloads the first time for All the Mods 10, most of it straight from CurseForge.

Which modpacks work?

Any NeoForge, Forge, Fabric or Quilt pack, or a plain server jar. New world also starts a server from a Modrinth or CurseForge pack, a Server Files zip, plain Minecraft or Paper.

Do I have to change my router?

No. The free playit tunnel gives the game a fixed address. Friends’ downloads go through a Cloudflare quick tunnel, or a fixed Tailscale address that stays the same after a restart.

What does it cost?

Nothing. Fenrir and Fenrir Connect are free, and so are the playit tunnel for the game and the Cloudflare quick tunnel for friends’ downloads. A paid playit TCP tunnel is an option, never a need.

Can I close Fenrir without stopping the world?

Yes. Quit asks whether to stop the server or keep it running. A kept world, the playit agent and the Cloudflare tunnel carry on, and the next Fenrir takes all three over. Players stay connected.

Where do I start when something is wrong?

Open the Doctor. It checks Java, memory, ports, mods, tunnels, friends’ links, backups and more, and most findings have a one-click fix.

To ask someone for help, Settings → About → Create support bundle writes one zip with the logs, the Doctor’s findings and your settings, with every key, password, webhook and friend key removed.

Is Fenrir safe to run?

Fenrir installs for your Windows account only, with no administrator rights. Windows asks for permission only when you choose something that needs it, such as letting friends through the firewall. Removing mods puts every original game file back, and Settings lists everything Fenrir changed on this PC, from its files in your games to firewall rules and router ports, each with its way back.

What leaves your PC: update checks with GitHub, the mod sites you install from, the tunnels and addresses you switch on, and the AI provider you choose (if you choose one). There are no analytics and no account. To remove Fenrir, use Apps in Windows Settings, then delete its folder; your worlds and servers stay where they are.

Why TLauncher? Can a friend use the official Minecraft Launcher?

Fenrir Connect sets everything up in TLauncher by itself: the modpack, its loader, the memory, and the world to join. That is why it is the launcher it asks for.

A friend with the official launcher can still join. The world accepts every account, because TLauncher accounts cannot pass Microsoft's account check, so the whitelist decides who gets in. They set up the same modpack version themselves, and Fenrir Connect's checks do not cover their launcher.

Who makes Fenrir?

Fenrir is an independent project by iksamxul, published on GitHub, where every release and its checksums are.

Friends and links

A friend’s card says “files behind”.

They press Update & Play in Fenrir Connect. Only the files that changed download.

The game says a friend is “not white-listed”.

Press Whitelist on their row in the Friends card, or add the name on the Players page. It has to be the exact TLauncher name, and case matters.

A friend’s app says “Your host is out of reach”.

Your Fenrir or your tunnel is down, or the Cloudflare address changed. Send the new link, or turn on the address relay so their apps follow a new address by themselves.

The Dashboard says friends are still on the old link.

Open the Friends card, press Copy link on each friend and send it. A fixed Tailscale address stops the link from changing after a restart.

Fenrir says friend keys are missing from the settings.

Press Restore the keys. Before any change that leaves fewer keys, Fenrir keeps the list in its key ledger. Skip it if you removed those keys on purpose.

A friend asked for a hand and has no answer yet.

Open the asks card on the Dashboard and choose Restore their things, Whitelist or Answer. They hear back in their app, and the Doctor reminds you after half an hour.

The Doctor says a Minecraft-typed playit tunnel points at the Fenrir Connect port.

playit cannot carry the friends’ link on a Minecraft-typed tunnel. Delete that tunnel in the playit dashboard, or make it a TCP tunnel (a Premium option). Friends use the fixed address or the quick tunnel meanwhile.

Windows SmartScreen blocks the Setup.

Choose More info, then Run anyway. Fenrir is not signed by a big publisher, so Windows asks the first time.

The server

The server crashed three times.

Three crashes in ten minutes stop the automatic restarts, and the banner names the mod the last crash report points at. Open the Doctor, switch that mod off and press Start.

The Doctor says the view distance is a lot for my friends.

Press Set 8 and 6 while the server is stopped. The next start uses a view distance of 8 and a simulation distance of 6, which a heavy pack carries better.

The Doctor found empty region files in the world.

Press Remove the empty files while the server is stopped. Minecraft writes a region file again when a chunk needs it, and backups get smaller.

The Dashboard shows a server “taken over from the previous Fenrir”.

Nothing to do. That is the world that kept running while Fenrir restarted or updated.

The Doctor says this PC goes to sleep.

If this PC hosts while nobody sits at it, set Sleep to Never on power in Windows Settings → System → Power. Fenrir keeps the PC awake while it matters, and the power plan decides the rest.

Backups and updates

Fenrir says “Cloud backups are not uploading”.

Open Network & Cloud, pick your provider and press Reconnect.

Fenrir says “The cloud has no copy of the world yet”.

Press Upload latest now, or wait for the next backup.

The last restore drill failed, or none has run yet.

Go to Backups → A way back → Try a restore. Fenrir unpacks the newest checked archive beside the backups, reads the world in it and removes the copy again, so you know it comes back.

The Doctor says “The safe pack update has never run on this PC”.

Go to Server Pack → Rehearse an update while nobody plays. It runs the whole update path with the version you already run, so your first real update is not its first run.

Other games

Can Fenrir mod games other than Minecraft?

Yes. Fenrir opens on the Games page, which finds the games on your PC from Steam, Epic, GOG, Ubisoft, EA and Xbox. Thunderstore mods install with one click for around 300 games, GameBanana for Half-Life 2 and Portal, and Nexus Mods are searched in Fenrir and downloaded on Nexus's page. Any game also takes a .zip, .7z or .rar.

Can Fenrir show games I own but have not downloaded?

Yes. Under your games, Not installed lists what your Steam, Epic and GOG Galaxy libraries hold on this PC. Fenrir reads it from the launchers’ own files and never asks for a login. Open a game to see what it is like before you download it: what it is, screenshots, the trailer (it plays on Steam), its genres and the engine it is made with, from Steam’s store and PCGamingWiki. Install opens its store, which asks where to put it, and Mash it up plans a mashup with it already.

How do I get my game back the way it was?

Open the game and press Remove all from the game. Fenrir keeps every file a mod replaced and puts it back, and takes out every file it placed. Nothing is deleted that Fenrir did not place unchanged: a settings file the game edited is kept in the game's hidden .fenrir-kept folder, and a file a game update replaced stays, with the old one kept there too.

Why does Fenrir leave PUBG alone?

Its anti-cheat bans accounts for programs that change the game, even ones that are not for cheating, and there are no unbans. Fenrir shows such games and never touches their files. The same goes for other online shooters with that kind of anti-cheat.

A modded game crashed. Which mod was it?

If you started it from Fenrir with its mods, a notification has already told you which mod is likely. Open the game's page: When it crashes reads what the game wrote and what its mod loader wrote (BepInEx, MelonLoader, Unity and Unreal games, Script Hook for GTA V, SKSE and crash loggers for Skyrim, tModLoader), and Windows' own record of the crash. A mod whose file is named in the error is likely to blame, one named further down may be. Press Take it out, or Take it out and play to try again straight away. Fenrir never blames the game's own files or the mod loader itself; when the loader failed, it says so.

Can I keep different sets of mods for one game?

Yes. On a game's page, Mod sets saves the mods that are on, in their order, under a name, and Use switches back in one press. Fenrir also remembers the mods each Play used: when a new mod breaks the game, Go back to these brings back the set you played with before. Mods installed after a set was saved are turned off, and mods that are gone are named.

Does Fenrir update my mods?

For mods from Thunderstore, yes. A game's page says which have a newer version, with Update for one and Update all. Each mod keeps its switch and its place in the order, and a mod its maker has deprecated is marked. Fenrir looks again every six hours, or when you press Check again. A file you added yourself has no version to compare, so it stays as it is.

Can I use GTA V mods and still play GTA Online?

Yes, one at a time. Play Story Mode with mods puts them in and starts the game without BattlEye; they come out when the game closes. Play GTA Online always starts a clean game, and waits while mods you installed by hand are still in the folder. This works with the Steam copy (Enhanced or Legacy). Script Hook V only works with the game version it was made for, so Fenrir fetches it only when it matches yours.

Why do Nexus mods need a click on Nexus's page?

Nexus Mods lets a public app download only through its own registered connection, and each person downloads their own copy. Press Download on Nexus, choose Manual download there, then From Downloads… in Fenrir installs the file and remembers which mod it is, so a newer download replaces it.

Can my friends play on a server with the same mods?

Yes, for Valheim, Palworld, 7 Days to Die, Terraria, GTA V (through FiveM) and Skyrim Together. Open the game in Fenrir: its server card installs the server, starts it, and puts the same mods on it as in your game. Valheim gives friends a join code, so nobody needs router ports or a VPN; for the others, the card shows the address to give them and can open the ports on your router.

Do my game servers get a console and backups like the Minecraft world?

Yes. Pick the server in the switcher at the top of the sidebar, or press Open in Servers on its card, and Dashboard, Console, Players, Server settings, Backups and Mods show that server: Start and Stop, its live log, who is on, its settings, and backups of its world. A restore needs the server stopped, and keeps the world as it was first so it can be undone.

How do friends get the same mods?

Turn on Share with friends on the game’s page. In their Fenrir Connect the game appears on the Games page: Get ready puts the same mods into their own copy, from where the mods are published, and Join starts the game for your server. Nothing of yours is copied to them, and their own mods stay as they are. A Nexus Mods file they download themselves, in two clicks, because Nexus asks everyone to. If you stop sharing a game, it stays on their Games page with Take them out until its mods are out, and uninstalling Fenrir Connect takes them out of every game first.

Can I start a game server from my phone?

Yes. Fenrir Link’s Dashboard lists every game server set up on your PC, with who is playing and the join code, and starts or stops it. Stop asks first, and asks again if friends got on meanwhile. The sites and apps your PC hosts are there too, with Start, Stop and a Copy button for each public address.

Can I send a friend a link to one game?

Yes. On the game’s page, Invite a friend… makes a link for one friend, new or not. It opens a page for that game with Fenrir Setup; once Fenrir Connect is in, it opens straight on that game, so Get ready and Join are one press each. The link only works for that friend, and stops if you revoke their key.

Can friends get a mod I made?

Yes. On a shared game’s page, press Let friends get it beside a mod you added as a file. Their Get ready then fetches it from your PC and checks it before it goes in. They get the mod as you added it, never settings the game wrote into it since. Use it only for mods you made or may pass on; downloads from Nexus Mods never go this way.

Where do I find mods for my games?

On the Games page, under your games, Discover shows the mods people play most for each of them, from Thunderstore, GameBanana and Nexus Mods. Install works in one press where the site allows it; Nexus mods open on their page. A game’s own page searches each site too.

What is a mashup?

One game played inside another. The Mashups shelf on the Games page has SkyCraft, where you play Skyrim as a Minecraft player, and Skate Warfare, which joins MW2, Skate 3 and a Minecraft world. Both come from their makers. Install puts a mashup into its game and Remove takes every file out again, as for any mod. Friends with Fenrir Connect get it with Get ready.

Can I mash up my own games?

Yes, up to four at once. Mash up games… on the Mashups shelf takes the game you play in and up to three more, and what each one brings: its world and maps, player and movement, physics, weapons, enemies, vehicles, building, music, look, rules or multiplayer. Fenrir reads each game: what it is made with, its graphics, and where a plugin can go in. A game you own but have not downloaded can join too: Fenrir plans it from the engine PCGamingWiki names, and its plugin loader comes once it is installed.

It then sets up a project in Documents\Fenrir Mashups: a brief for a coding agent, a starter that already loads in the game you play in, and the bridge between the games. Build with AI builds it inside Fenrir. You can also copy the brief to Claude Code, Codex or another coding agent. Building a mashup is real programming: expect to work on it step by step with the AI.

Does the AI know how other people modded these games?

Yes. Every project comes with know-how from universal-modder (MIT), where coding agents write down how they modded real games: the guide for each game's engine, and field notes by other modders on the games you picked. For GTA V with Minecraft, that is the write-up of a working Minecraft inside GTA V. Each game that brings something also takes the lightest way to deliver it: its things brought across, its rules rebuilt as a small simulation, or both games running at once. The Studio shows the way under each game as you pick. With its switch on, Claude Code started in the project can add universal-modder's skills too. Fenrir ships a copy it has read, and fetches none of it while it runs.

Can a mashup break my saves, or send friends something it should not?

A mashup's first Play keeps the game's saves first, wherever the game keeps them, and the game's page has Put back for them (with the game closed). And before friends can get a mod from your PC, Let friends get it looks through it: a file copied from the game, or a key or password left in a file, stops it there; decompiled code or your user folder written into a file is shown to you first.

Which AI does the mashup builder use?

The one you pick with Choose the AI… on the Mashups shelf:

  • a model in LM Studio on your PC. Fenrir starts LM Studio’s server, loads the model, and unloads it again when a game starts.
  • Ollama.
  • OpenRouter, Anthropic, OpenAI or Google Gemini, with your own key. The key is kept encrypted by Windows for your account and sent only to its own provider.
  • Any other OpenAI-compatible server.

The builder works only in the project’s folder and runs no command except the project’s own build. It asks before it builds anything, puts it into a game or starts the game for you to try it. After you play, it reads what the mashup wrote to its log and fixes what it shows. Its questions show in Fenrir Link too, so you can answer from your phone.

Sites and apps

What can Fenrir put online?

Anything on this PC, from the Sites & apps page:

  • a folder, as a website. Fenrir serves its files itself, with no folder listings and nothing hidden, like .git or .env.
  • an app or project. Fenrir starts it in its folder with the command you give, sets PORT to its port, keeps what it prints in its log, and stops it with everything it started.
  • a port a program on this PC already serves, such as a dev server.

The Minecraft world and your game servers are on the same list.

Who can reach what I host?

Only this PC, until you switch something on. Each item has its own switches:

  • Free public address: an https address from Cloudflare’s quick tunnels that anyone can open, with no account and no router changes. It changes each time the item starts.
  • Home network: phones and PCs on your own network can open it. If the Windows Firewall stops them, Let them in… asks Windows once to let them through.
  • Start with Fenrir: it comes back whenever Fenrir does.
Can my sites use my own domain?

Yes, when the domain is on Cloudflare (a free account works). On Cloudflare, under Zero Trust → Networks → Tunnels, create a tunnel and copy its token, the long text at the end of the install command it shows. Paste it into Your own domain on the Sites & apps page and press Start: Fenrir runs the tunnel itself. Then add a public hostname on Cloudflare for each site or app, pointing at the address it shows as “This PC”, and type that hostname on the item in Fenrir. Windows keeps the token encrypted for your account, and Fenrir never shows it again.

Is it safe to host from my PC?

A website folder shows only the files in that folder, never the rest of the PC, and never hidden files. An app is as safe as the app itself: whoever has the address can use it, so put online only what you mean to share, and switch the public address off when you are done. Nothing is public until you switch it on, and quitting Fenrir takes your sites and apps offline with it.

Ask Fenrir and AI apps

What can I ask Fenrir?

Press Ctrl+K, type a sentence and choose Ask Fenrir. Fenrir understands the everyday ones on its own: start or stop a server, who is on, back up, say something to everyone, plan a game night (“game night Friday at 8 on Valheim”), invite a friend, turn a mod on or off, play a game, why a game crashed, find or install a mod by its name, use a mod set, update a game's mods. It answers questions at once, and lists every change with a tick box: nothing happens until you press Do it.

Do I need an AI for Ask Fenrir?

No, not for the everyday sentences above. For anything else, Fenrir uses the AI you picked for the mashup builder: a model on this PC through LM Studio or Ollama, or a provider with your own key. Fenrir never starts LM Studio for a question; if it is not running, Fenrir says so.

Can Claude Code or Claude Desktop use Fenrir?

Yes. In Settings, switch on AI apps and press Add to Claude Code or Add to Claude Desktop. They then see what runs and who is on, read a server's log, list your games and mods and the planned game nights. Choose Look and change to let them start and stop servers, back up, plan game nights, invite friends and turn mods on or off. Other apps that speak MCP, such as Cursor, take the setup from Copy the setup for another app.

Is it safe to let an AI app use Fenrir?

Apps start by looking only. With Ask me first (on unless you turn it off), every change waits for your Yes in a Windows dialog of Fenrir's own, which an app cannot answer for you, and nothing happens if nobody answers. Inviting someone, installing a mod and putting a site online always ask, even with Ask me first off, and Fenrir names exactly what will happen first (for a mod, its maker, downloads and what it needs). Apps reach Fenrir through a small bridge on this PC, the key stays encrypted by Windows for your account, an invite's link shows only in Fenrir's window, and an AI can never run a console command or read your files. Every change lands on the timeline with the app's name, and switching AI apps off locks them out at once.

Fenrir itself

The timeline says “Fenrir stopped without a goodbye at …”.

Nothing to do if its watcher started it again, which it does within seconds. The Doctor’s note carries the fault log’s last words. If it keeps happening, send a support bundle.

The Doctor says “Fenrir’s timed work stopped at …”.

Fenrir starts a fresh loop by itself. If the Doctor still says it, quit Fenrir and open it again. The world keeps running meanwhile.

Does Fenrir update itself?

Yes. Once a day it looks for a new build and gets it ready in the background. Every update is signed by Fenrir’s publisher and checked before anything on your PC changes, so a tampered file or a fake website gets nowhere. By default it then waits for you: press Update now on the Dashboard or in Settings → About. Fenrir closes for a few seconds and opens again; the world keeps running and nobody is kicked. If the new Fenrir does not start properly, the one you had comes back by itself. Settings → Behaviour → Fenrir updates can let it update on its own once nobody has played for ten minutes, or stop the checks.

Fenrir says “The update did not start properly, so Fenrir went back to the build it had”.

Nothing was lost: your Fenrir runs as before. Fenrir does not try that update again by itself. Settings → About → Try again fetches it afresh; if it fails again, send a support bundle.

The Doctor says “The update feed was not signed by Fenrir’s publisher”.

Fenrir ignored that feed and installs nothing from it; your Fenrir keeps working as it is. It usually means something between your PC and the website changed the file. If it stays that way for days, tell whoever publishes Fenrir.

Friends’ download links said “not found”.

A Fenrir installed with Fenrir Setup had no copy of the friends’ app to hand out. Since this build it gets Fenrir Connect and Fenrir Setup from its own release, checked the same way as its updates, as soon as you share a world. If the Doctor says it could not, press Get it now.

Fenrir Link

What is Fenrir Link?

The phone app for Fenrir and Fenrir Connect. Hosts run their server from the phone: a dashboard with the last half hour, the players and the whitelist, the whole console, and tools from backups to the note to friends. Friends see whether the world is up, answer game nights, chat, ask their host for a hand and share pictures. It is on the Fenrir Link page.

Where is my code?

On the PC that hosts, open Fenrir: the Fenrir Link card on the Dashboard shows it. Friends open Fenrir Connect: their code is on the You page. In the app, press +, then Scan a code.

Why is it not in the App Store or Google Play?

Fenrir is free and has no store accounts. Android installs the APK straight from the download. On an iPhone, point the Camera at your code and add the page to your Home Screen: it is Fenrir Link itself, served by your host’s Fenrir, with no store and no computer. The full app file is there too, for AltStore or Sideloadly.

The Fenrir Link card says the code needs a secure address.

Your server’s code only works over https. Turn on Cloudflare or Tailscale under Network & Cloud, then the card shows the code.

My code stopped working.

Its key was replaced, or the phone remote was turned off. Show the code again in Fenrir or Fenrir Connect and scan it. The app says so when a code no longer works.

No question matches that. Try a shorter word, or open the Doctor in Fenrir.

Still stuck?

Send a support bundle.

Settings → About → Create support bundle writes one zip with the logs, the Doctor’s findings and your settings. Every key, password, webhook and friend key is taken out first, so it is safe to share.
